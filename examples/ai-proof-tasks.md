# Example: ai-proof-tasks

## The request

> Use ai-proof-tasks. Here's my Year 10 homework: "Write 300 words explaining the difference between RAM and ROM." Half the class will paste it into ChatGPT. Redesign it.

## Diagnosis

Pasted into an AI, this task skips everything: recall, choosing the important differences, and explaining them. It tests whether a student can copy text, not whether they understand memory.

## What the skill produced

### The task (student-facing)

**RAM vs ROM: catch the AI out**
*AI level: AI to check. Do Parts 1 and 2 yourself first.*

**Part 1: from memory (5 minutes, no notes, no devices)**
Write down everything you remember about RAM and ROM. Bullet points are fine. Don't fix it later: this part shows what you already know.

**Part 2: your own device (5 minutes)**
On a laptop or PC, open Task Manager (Windows) or Activity Monitor (Mac), or ask an adult whose device it is first. Write down:
- how much RAM the computer has
- how much of it is being used right now
- which app is using the most

Explain in two sentences why that number would drop to zero if you switched the computer off.

**Part 3: catch the AI out (15 minutes)**
Below is an answer an AI wrote. It has **four mistakes**. Find each one, say why it's wrong, and write the correct version.

> RAM and ROM are both types of primary memory. RAM is volatile, so it loses its contents when the power is turned off. ROM stores your saved files and documents so they are kept safe. RAM can be read from and written to, while ROM can usually only be read. Virtual memory is extra RAM that the computer downloads from the internet when it runs out. ROM is much larger than RAM in most computers, which is why it holds the operating system while the computer is running.

**Part 4: use AI to check (optional)**
Ask an AI: "Quiz me on RAM and ROM, one question at a time, and don't tell me the answer until I've tried." Paste the conversation and write one thing you learned.

**Hand in:** Parts 1 to 3 (and 4 if you did it).

### Teacher notes

**The four planted errors:**
1. ROM stores saved files. Saved files go on secondary storage; ROM holds start-up instructions.
2. Virtual memory is downloaded from the internet. It's part of secondary storage used as if it were RAM.
3. ROM is much larger than RAM. ROM is small in most computers.
4. ROM holds the operating system while it runs. The running OS is loaded into RAM from secondary storage.

**Marking guide (10 marks):**
- Part 1 is not marked for accuracy. It's a retrieval check: note what's missing for the next starter.
- Part 2: sensible readings (1); a correct explanation using "volatile" (1).
- Part 3: 2 marks per error (1 for spotting it, 1 for a correct fix), max 8.

**Why this protects the learning:** Part 1 forces recall before any tool, Part 2 can't be answered by an AI, and Part 3 makes the AI's weakness the lesson. A student who just pastes the task in gets nothing useful back.
