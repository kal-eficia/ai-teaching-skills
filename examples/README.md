# Examples

Real requests and what the skills produced, so you can judge the quality before you try one. All examples use Cambridge IGCSE Computer Science 0984, because that's what I teach. Student data is invented, and students appear as placeholders like [S1], never real names.

## What testing changed

Running the skills on real tasks before publishing turned up four fixes:

1. **Names vs data protection.** The report, parent-message and recall-starter skills asked for student names while the data guidance said to anonymise. They now draft with placeholders like [S1], and the teacher swaps names in afterwards.
2. **No code available.** no-answer-patterns told the AI to check keys with code, but a teacher pasting it into some chat assistants can't run code. It now includes a by-hand method and says when a key was checked by hand.
3. **"All of the above" moved.** The key fixer moved fixed-position options. It now keeps them in place (see [no-answer-patterns](no-answer-patterns.md)).
4. **Peer assessment vs house rules.** peer-assessment-designer now respects a "students don't mark their own work" house rule.
