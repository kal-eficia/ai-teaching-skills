# Year 8 Computing: Python Programming Basics (half-term scheme of work)

## Assumptions

- 6 weeks, 2 x 50-minute lessons per week, 12 lessons in total. Dates are left as week numbers because no calendar was given; drop in your real dates and check them against any inset days or trips.
- Students have used Scratch in Year 7 (sequence, loops, if blocks, variables) but have never typed code. Scratch is used throughout as the bridge: every new Python idea is linked to a block they already know.
- Every student has a computer in each lesson and uses a browser-based Python editor (for example Trinket, Replit or your school's IDE), so there is nothing to install and the same setup works at home.
- Whole class, one teacher, mixed ability. Each lesson has a core task and a stretch task.
- No specification is attached, so objectives link to the National Curriculum KS3 computing strand: "use two or more programming languages, at least one of which is textual, to solve a variety of computational problems; make appropriate use of data structures; design and develop modular programs that use procedures or functions".
- One new idea per lesson. No checkpoint or assessment sits in a lesson that introduces new content.
- Lists, functions and while loops are deliberately left out of this half-term. While loops are offered as stretch in Lesson 9 and become the opening of the next unit.

## The dependency chain

print and running code, then variables, then input (needs variables), then arithmetic (needs variables and input), then if/else (needs variables and comparisons), then elif, then for loops (needs variables and, usefully, if). The assessment draws on all of it.

## Key vocabulary by unit

- **Getting started (L1 to L2):** program, code, run, syntax, error, bug, debug, print, string, integer, float, variable, assign.
- **Input and arithmetic (L3 to L5):** input, output, convert, operator, expression, order of operations, modulus, integer division.
- **Selection (L6 to L7):** condition, comparison, if, else, elif, indentation, Boolean, True, False.
- **Iteration (L9 to L10):** loop, iterate, repeat, range, count, infinite loop (stretch).

## Common misconceptions by unit

**Getting started**
- Python is fussy because it is "broken": it is not, it needs precise syntax and the error message is helping.
- Capitals, spelling and brackets do not matter (they do: Print is not print).
- Quote marks around a variable name print the name, not the value.
- An error means "I'm bad at this", not "the computer is telling me where to look".

**Variables and input**
- A variable holds the name, not the value (confusing `name` with `"name"`).
- `=` means "equals" as in maths: in Python it means "store this value in".
- input() returns a number if you type a number: it always returns text, so "5" + "5" gives 55.
- A variable keeps old values after you reassign it.

**Arithmetic**
- `/` and `//` do the same thing.
- `*` is written as x.
- Order of operations works left to right, with no brackets needed.

**Selection**
- `=` and `==` are interchangeable.
- Forgetting the colon or indentation is "just formatting": it changes the meaning.
- else needs a condition.
- All elif branches run when true (only the first true one runs).

**Iteration**
- range(5) gives 1 to 5 (it gives 0 to 4).
- The loop variable has to be created before the loop.
- Code outside the indent runs every time round the loop.

## Checks against the planning rules

- Every taught idea (print, variables, input, arithmetic, if/else, elif, for) is taught once and retrieved at least twice through the starters, Checks 1 and 2, and the revision stations.
- No lesson depends on something taught later.
- Creative lessons (L1 poem, L10 build) and exam-style lessons (L5, L11, L12) are present in every fortnight.
- Two flex lessons (L8 and L11), one in every six.
- No checkpoint sits inside a lesson that introduces new content: Checks 1 and 2 live in consolidation lessons, and the assessment has its own slot.
