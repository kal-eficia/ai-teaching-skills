# Year 9 Practice Sheet: Equations with the Unknown on Both Sides

**Name:** ______________________  **Date:** ______________

**Assumptions:** the class has met "do the same to both sides" and can solve one-sided equations. Questions are graded from routine to stretch, with a worked example at the top and a full answer key at the end. The method used throughout is: (1) collect the x terms on the side where the x coefficient is bigger, (2) collect the numbers on the other side, (3) divide, (4) check.

---

## Worked example

Solve 5x + 3 = 2x + 15

| Step | Working | Why |
|---|---|---|
| 1 | 5x + 3 - 2x = 2x + 15 - 2x, so 3x + 3 = 15 | Subtract 2x from both sides (removes the smaller x term) |
| 2 | 3x + 3 - 3 = 15 - 3, so 3x = 12 | Subtract 3 from both sides |
| 3 | x = 12 / 3 = **4** | Divide both sides by 3 |
| Check | Left: 5(4) + 3 = 23. Right: 2(4) + 15 = 23. | Both sides match |

**Tip:** always subtract the *smaller* x term, so you keep a positive number of x's.

## Answers

**Section A**
1. 3x + 1 = 10, 3x = 9, **x = 3**
2. 4x + 2 = 18, 4x = 16, **x = 4**
3. 2x + 7 = 19, 2x = 12, **x = 6**
4. 3x + 4 = 19, 3x = 15, **x = 5**
5. 5x + 1 = 11, 5x = 10, **x = 2**

**Section B**
6. 4x - 5 = 15, 4x = 20, **x = 5**
7. 4x - 4 = 8, 4x = 12, **x = 3**
8. Subtract 2x: 9 = 3x - 6, so 15 = 3x, **x = 5**
9. Subtract 3x: 4 = 4x - 12, so 16 = 4x, **x = 4**
10. Subtract 4x: -3 = 5x - 23, so 20 = 5x, **x = 4**

**Section C**
11. Subtract 3x: 10 = 2x + 4, so 6 = 2x, **x = 3**
12. Subtract 2x: 5 = 4x + 1, so 4 = 4x, **x = 1**
13. Subtract 5x: -1 = 3x + 11, so -12 = 3x, **x = -4** (check: -21 = -21)
14. Subtract 4x: 3 = 2x + 4, so -1 = 2x, **x = -1/2** (check: 1 = 1)

**Section D**
15. a) 5x - 3 = 2x + 12, so 3x = 15, **x = 5**. b) 5(5) - 3 = **22 cm** (check: 2(5) + 12 = 22)
16. 6n - 7 = 2n + 21, so 4n = 28, **n = 7** (both get 35)
17. a) They subtracted 2x correctly but then added 5 to 17 instead of subtracting it (22 should be 12). b) 4x = 12, **x = 3**. Check: 6(3) + 5 = 23 and 2(3) + 17 = 23.

**Challenge**
18. 3x + 6 = x + 14, 2x = 8, **x = 4**
19. Left side: 5x - 5. Right side: 2x + 10 + 3x - 1 = 5x + 9. So 5x - 5 = 5x + 9, which gives -5 = 9, which is never true. **There is no solution**, because the x's cancel and leave a false statement. Lines with the same gradient and different intercepts never meet.

---

### Teacher notes
- Common errors to watch for: subtracting from one side only; adding when they should subtract; sign slips when the constant is negative (Section B); stopping at 3x = 12 without dividing.
- Q17 and Q19 are good for discussion. Q19 is deliberately a stretch (no solution), so it can be dropped for a mixed-ability group.
- Encourage the "check by substituting" habit on every question. It is the quickest way for pupils to self-correct.
